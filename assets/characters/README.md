# 人物素材集

把角色素材图放进对应子文件夹（如 doraemon/），出图节点会用这些真实素材做合成，不再用 SVG 手画人物。

## 格式建议
- PNG，**透明背景最佳**（角色能干净地摆到任意背景上）；JPG 也行但会带白底。
- 尺寸越大越好（>=600px），清晰。
- 多给几种姿势/表情更好（惊讶 / 开心 / 思考 / 指向 / 摊手 / 举牌…），不同分镜能挑到合适的；3-6 张起步即可。

## 命名（可选但推荐）
用描述性文件名，方便 AI 按分镜挑图，例如：
- doraemon-surprised.png（惊讶）
- doraemon-pointing.png（指向/介绍）
- doraemon-thinking.png（思考/拷问）
- doraemon-happy.png（开心）
- doraemon-prop-door.png（掏任意门）
名字随意也行，AI 会按内容大致判断。
